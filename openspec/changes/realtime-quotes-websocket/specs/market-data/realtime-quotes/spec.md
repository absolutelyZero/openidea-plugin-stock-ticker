# Spec Delta

## Purpose

通过宿主持有的后台 WebSocket 接收行情推送，让报价在面板可见、用户静止时也能持续更新；当实时通道不可用时自动退回轮询，保证报价不中断。

## ADDED Requirements

### Requirement: 实时推送更新报价
系统 SHALL 在实时连接可用时，依据推送帧增量更新对应标的的最新价、涨跌幅与行情时间，且不需要用户操作或手动刷新。

#### Scenario: 收到某只标的的推送帧
- **WHEN** 实时通道推送某只自选股的成交价帧
- **THEN** 该行报价在 2 秒内更新，且状态行的行情时钟前进

#### Scenario: 自选股包含指数
- **WHEN** 实时通道同时推送指数与个股
- **THEN** 指数行与个股行各自更新，互不覆盖

### Requirement: 实时不可用时降级轮询
系统 SHALL 在无打开项目、连接建立失败、连接关闭或数据源不支持推送时，继续使用现有 HTTP 轮询获取报价，不得让报价停止更新。

#### Scenario: 没有打开的项目
- **WHEN** 当前窗口没有可绑定的项目
- **THEN** 系统不建立实时连接，继续按既有轮询与事件心跳刷新

#### Scenario: 实时连接反复失败
- **WHEN** 连续多次连接失败
- **THEN** 系统保持轮询可用，状态行可见地说明实时通道不可用，且不进入紧密重试

### Requirement: 连接生命周期与重连
系统 SHALL 在激活时按需建立实时连接、在停用或视窗关闭时释放；连接意外关闭后 MUST 按指数退避重连，且同一插件同时持有的连接不超过宿主的 8 条上限。

#### Scenario: 连接被对端关闭
- **WHEN** 推送服务关闭连接
- **THEN** 系统按退避间隔重连，重连成功后恢复增量更新

#### Scenario: 插件被停用
- **WHEN** 用户禁用或卸载插件
- **THEN** 实时连接被关闭，不留后台连接

### Requirement: 推送与轮询数据一致
系统 SHALL 把推送帧与轮询结果写入同一份报价快照，同一标的以行情时间较新者为准，不得让旧数据覆盖新数据。

#### Scenario: 轮询结果晚于推送到达
- **WHEN** 一次轮询响应包含比已收到推送更早的行情时间
- **THEN** 该标的保留较新的推送值

### Requirement: 实时通道失败可见
系统 MUST 在实时通道因未授权、端点不可达或协议不兼容而不可用时给出可见提示，不得静默降级。

#### Scenario: 行情 host 未授权
- **WHEN** 实时连接所需的 `net:<host>` 未被授权
- **THEN** 状态行提示需要授权，并说明当前仍在用轮询
